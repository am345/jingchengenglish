# 制作与路径约定

## 布局和动作

老师的脸、曝光、右侧站位、尺度在首尾参考图中固定。课件 JSON 的 `teacher` 是全课唯一坐标变换，不在镜头间变更；最好直接用包含完整 1280×720 画布的参考图约束生成。文字由 Remotion 渲染，保持字形与行位置恒定，强调只变颜色。

提示词写清每个发声区间、黑板单词中心/手指接触点、身体朝向与结束动作。三个词属于同一语义组就一口气生成一个连续镜头：转向黑板一次，按顺序指出并读完所有词及释义，最后收手回头。不能用词间切片、人物缩放跳变或中途回正掩盖失败。

局部某个词口型失败时，保留配音与坐标，生成覆盖**完整原教学段**的新候选。小段仅用于定位问题/单独试听，不能把不同候选的小段重新贴入已交付人物镜头。候选编号递增，记录实际生成量；先看原片动作，再花时间抠像和渲染。

## 音频与时间线

配音是 CosyVoice3 新文本生成，R6 提供真人课堂表演、R2 提供声学条件；不是把 Grok 原声送入声线转换。固定 speed=1，保留真实节奏。参考基准的通过只代表音色路线，不自动批准新文本的读音与停顿。

母带先写出 90 秒自然时间线，留段间教学停顿；Grok 提示词随后跟随实测发声区间。没有任意输入音频的 `reference_to_video` 参数；不要宣称提示词保证逐字同步。只允许经过复核的整段常量平移，保留原样本与边界空白，不分词改速。本工具不自动平移或修改已确认音频。

## 渲染约束

当前模板支持 1280×720、24fps、2160 帧的正式成片。抠像会拒绝不同 native fps 的源，不会强制 `-r 24` 修正。一个 `clips[]` 条目只能选一个源的连续帧，缺帧就失败；固定的源头尾裁切只允许在已确定的静默余量内安排。

`teacher_frames` 引用抠像目录，其 manifest 记录原始源哈希、帧数和模型。人物 PNG 保持原画幅。桥接课件发生在两个 clip 之间的预定间隙，不作为口型检测的临时遮挡。桥接不代表老师保持了一张静帧。

本仓库的 courseware-demo 是可运行模板；旧课程的精确字体、板书坐标、人物素材和时间线属于私有输入，首次迁移必须拿定版截图复核。模板可编辑，但不得在同一课中随意改变人物尺度。

## Mac 可选兼容后端

```bash
mkdir -p .cache/bin
swiftc tools/macos/cutout.swift -o .cache/bin/cutout
swiftc tools/macos/measure_faces.swift -o .cache/bin/measure_faces
```

配置 `matte.backend="vision"`、`qa.face_backend="vision"` 并指定编译输出路径。Windows/Linux 用 RVM + YuNet。抠像后端只改变 alpha；检测后端只影响评估，不处理嘴部。模型/检测器变更会改变方法指纹，必须重新校准。

## 目录

- `jingcheng/`：配置、控制端、服务器传输、Grok 队列、抠像、渲染和 QA。
- `workers/`：上传到已部署 Linux 环境的 CosyVoice 任务。
- `remotion/`：跨平台课件模板和渲染入口，使用本机安装的 compositor。
- `tools/qa/`：从既有流程迁移的冻结窗口评测，取消旧电脑路径。
- `assets/`、`runs/`、`private/`：全部忽略，不发布用户素材、成片和日志。
- `config/local.toml`：本机私有配置；CLI 参数和环境变量可选择其他配置文件。
