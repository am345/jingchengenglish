# Repository scope

Work only inside this repository and configured new job directories. Read `README.md`, the project skill, and the relevant docs before production. Never import execution paths from an old workstation or unrelated production checkout.

Use `Config` for local/remote paths. Do not commit private media, model weights, keys, cookies, local config, logs or job outputs. Do not copy login state. Existing generation authorization remains valid; inspect paid-job manifests before any retry and never infer success from a timeout.

A teaching segment is one continuous native source. No wordwise candidate splicing, time stretching, held frames or synthetic mouths. Global teacher layout is fixed. Keep the complete frozen evaluation window set. Do not lower thresholds or change the detector to obtain a passing score.

Run `python -m unittest discover -s tests -v` and `pnpm --dir remotion run typecheck` for relevant changes. Media tests use synthetic fixtures; do not launch paid generation or production GPU jobs as a software smoke test. Report Windows/WSL and server validation separately from local tests.
